# テストセット(すべて架空・合成)

- ここにある音声は、**架空の台本(`spike/make_testset.py` 内の `LINES`)を OpenJTalk(pyopenjtalk)で合成した音声**に、合成した雑音を足したもの。実在の人物・会社・録音は一切含まない。個人情報なし。
- 実際の人の声・実際の会議室の録音ではないため、**文字起こしの誤り率・ノイズ除去の聞き取りやすさの結果は「近似」**。実機の会議音声での確認は別途必要。
- 再生成: `python spike/make_testset.py testset`(乱数固定)。

| ファイル | 内容 | 長さ |
|---|---|---|
| t01_clean | 1話者、雑音なし(基準。`t01_clean_ref.wav` は同じ音声) | 165秒 |
| t02_aircon | t01 + エアコン風の低域雑音(SNR 5 dB) | 165秒 |
| t03_keyboard | t01 + キーボード風のクリック列(SNR 5 dB) | 165秒 |
| t04_farmic | t01 を遠いマイク風(減衰 + 残響)に加工 | 165秒 |
| t05_overlap | 2話者の同時発話(正解は主話者の文のみ。難条件) | 56秒 |
| t06_long10min | 速度測定用の長尺(台本4周 + エアコン雑音 SNR 10 dB)。**サイズが大きいため Git に入れない**(再生成する) | 661秒 |

- 正解の書き起こしは `*.txt`(台本そのもの。句読点を含む。誤り率は句読点・空白を除いて計算する)。
- 制約: 合成音声は話速・抑揚が一定で、実際の会話(言い淀み・相づち・言い直し)を含まない。5〜30分の録音 5〜10本という SPEC の水準には届いていない(本数・長さとも不足)。
