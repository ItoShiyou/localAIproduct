# 無料版と有料版(確定 2026-10-04)

利用者の方針: 買い切りアプリなので、**無料版で使い続けられないようにする**。書き出しが無料だと「書き出して議事録を消し、少ない枠を使い回す」ことができるので、それも防ぐ。決定は競合調査(サブエージェント、下記)にもとづき、利用者の委任で確定した。

## 確定した線引き

| | 無料版(お試し) | 有料版(買い切り) |
|---|---|---|
| 精度 | 小さなモデル(Whisper small。合成音声で誤り 6〜9%) | 正確なモデル(large-v3-turbo。約 4%) |
| 量 | **累計 60 分**(これまでに文字起こしした音声の合計。議事録を消しても戻らない)、**1件 15 分**まで(録音も 15 分で自動停止) | 制限なし |
| 書き出し | **テキストのみ**、末尾に「無料版で作成」の一文 | Word・PDF・Markdown・テキスト・字幕・ノイズ除去後の音声 |
| 機能 | 取り込み・マイク録音・確認と修正・検索・議題/ToDo の欄・タグ | すべて(話者の判別・ノイズ除去・用語辞書、要約〈後から追加ダウンロード〉) |
| 上限に達したら | 文字起こしが止まり、そこまでの文字は残る。有料版にすると続きの区間から再開 | — |

- **保存数ではなく累計で数える**: 保存数(例: 5件)は「書き出して消す」で回せる。累計の時間は消しても戻らない。
- **使った量の記録**: 署名(HMAC)付きで、アプリのデータフォルダ・別の場所(macOS は `~/Library/Preferences/<識別子>.usage`)・OS の資格情報ストア(キーチェーン)の3か所に置き、最大値を使う。どこか1つ消されても書き戻す。署名が合わなければ使い切った扱い。「全データを削除」でも消さない。
- **限界(正直に)**: 端末の中だけの仕組みなので、3か所をすべて消す・アプリを改造する、といった手間をかければ破れる。目的は「割に合わない」ようにすること。オンラインの認証で数える案は、通信を増やす(端末の外に出さない方針と相性が悪い)ので採らない。
- **期間限定の全機能トライアルは付けない**(競合の tranext は7日)。代わりに、購入の不安を下げる**返金保証(14〜30日)を販売時に検討**(販売プラットフォームの機能。利用者が決める)。
- **価格は未定**(止まる対象)。参考の相場は下記。
- 有料版の判定はライセンス(`core::license`)につなぐ。それまでは、開発用のビルドと環境変数 `MINUTES_TIER=pro` は有料版、配布用のビルドは無料版で動く。
