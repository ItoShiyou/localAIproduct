# 2026-10-12 所有者の正式決定

Pro買い切り価格は3,980円、無料版は累計60分・1件15分。価格と既存上限を明記した質問に「確定でいいよ」と回答を受領。App Store Connectへの登録は未実施。Appleが返す地域別表示価格をアプリに表示し、文字列3,980円を購入処理へ固定しない。

無料版は既存実装の小さな文字起こしモデルとテキスト書き出しを保持。Proは高精度・ノイズ除去・辞書・話者判別・要約・各種書き出しを解放する。削除しても累計使用量は戻らない。独自キー・外部決済をMac版に用いない。Windows構成と販売コードは保持する。

対応OSはmacOS 12以降・Apple Siliconを維持する。同梱ONNX Runtimeの必要OSが14.0だったため、14以降へ変更する提案に対し「macOS 12対応を維持し、エンジンの再構築を続ける」と所有者が指示。公式ソースを固定して12.0をターゲットに再構築する。最小OS上の実機検証はビルドの最低OS表示確認と区別する。
