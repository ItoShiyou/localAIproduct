## 今回確認・修正したこと

- 既存Rustのライブラリテスト77件が通過。
- 既存React UIのTypeScript検査・production buildが通過。
- マイク録音の停止時、送信キューを待たずにバックエンドを停止し、0.5秒未満の末尾を送らない不具合を修正。
- 音声の書き込みに失敗したときは正常保存と区別し、既に保存できた部分を残す操作を用意。
- React StrictModeでマイク準備中に破棄された処理が録音を開始しないよう修正。AudioWorklet準備に失敗したときはリソースを解放。
- ドラッグ&ドロップ通知の登録完了前に画面が破棄された場合でも、通知を解除するよう修正。
- `npm run test:recording` に音声送信順序・停止待ち・送信失敗の回帰テストを追加。
- 同テスト2件が通過。Mac向け未署名アプリの再ビルドが成功（約824MiB）。
- `real_live` を Whisper small q5_1、CPU・6スレッドで実行。80.6秒の合成音声を実時間で投入し、最大待ち2区間、停止待ち0.8秒、仮の文16件でテスト通過。マイクUIの実機検証とは別。
- `real_asr` を large-v3-turbo q5_0、CPU・6スレッド、ノイズ除去なし、t01_cleanで実行。165.2秒の合成音声を88.9秒で処理、CER 4.10%、テスト通過。ビルドと並行実行したため、処理時間は単独性能の基準にしない。
- 最終のUI変更を含むMac向け未署名アプリの再ビルドも成功。実マイク・画面操作・通信監視は今回再実施していない。
- `npm run tauri` がUIフォルダから設定を見つけられず失敗する問題を、設定のある `src-tauri` からCLIを起動するラッパーで修正。
- ライセンス設定UIは既に接続済みだったため、SPECの「未接続」を訂正。
