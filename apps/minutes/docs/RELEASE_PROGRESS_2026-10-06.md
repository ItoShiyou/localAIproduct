# 販売前の安全性・Windows対応

## 今回の変更

- 起動時、録音中に終了した会議の保存済みPCMをWAVへ復元する。文字起こしは勝手に再開せず、利用者が原音を確認してやり直す。
- 受信した音声ブロックごとにバッファをフラッシュし、短い発話が認識区間の確定前に失われるリスクを減らす。ブラウザーから未送信の音声、OSの強制終了や電源断まで保証するものではない。
- 復元はストリーミングで行い、長時間の音声全体をメモリに読み込まない。WAVとデータベースの参照を保存した後にだけ元PCMを削除する。
- 復元できなければ元音声を保持し、次回起動時に再試行する。画面上は録音中ではなく失敗状態とする。
- Windowsでは録音ファイルの書き込みハンドルを閉じてから変換・削除。対応CPUを音声処理前に確認する。
- Windowsの配布候補はロジック試験と要約サイドカー確認を通過した場合だけ生成する。WebView2のオフラインインストーラを同梱する。

## 確認範囲

- Release・no-default-features: 81件成功（8.86秒）。
- Release・whisper,diarize有効: 81件成功（8.76秒）。ロジック試験であり、この回で新しい実音声の精度測定はしていない。
- UIの型チェック・本番ビルド、録音キュー2件、発言検索3件: 成功。
- macOSのminutes.app再ビルド: 成功（823.88MiB）。署名・公証と今回の実マイク強制終了試験は未実施。
- Windowsのネイティブ検証: https://github.com/ItoShiyou/localAIproduct/actions/runs/37448337720 。開始済みで、結果は未確定。

復元・端数サンプル・再起動の冪等性、保存先が使用できない場合の保持と再試行、短い音声のフラッシュを回帰試験に追加。子プロセスへテスト音声を入力し、OSから強制終了して再起動・原音復元・文字起こし再実行する試験に成功。30分相当のテスト音声を高速入力し、保存・最終処理・確定・書き出しする試験にも成功（実マイクでの30分連続録音とは異なる）。電源断と機器抜去は未確認。

Windowsは上記リンクの検証でtest、sidecar-check、small/turbo実認識、bundle、smokeがすべて成功。新しいプロセス復旧試験も今後Windows CIで実行する。実マイク・端末固有のハードウェアをこの成功で保証しない。

追加で無料版の最終音声ブロックを残り時間ぴったりに切り詰め、欠けた16ビット音声サンプルを明示的に拒否する。実モデルの試験は事前条件不足を成功扱いせず、明示実行・不足時失敗に変更する。
