# 2026-10-07 追加の販売準備検証

## 今回確認した範囲

- Free→Pro→Freeの3つのコンパイル済み別プロセスで同じ一時保存先を使い、音声・修正文・議題・決定事項・ToDo・参加者・タイトル・確定状態・タグ・検索結果・使用量が保持されることを確認。
- FreeのWord書き出し拒否、ProのWord書き出し成功、Freeへ戻したときの再拒否。ProのTXTには無料版の末尾表示を付けない。
- テスト認識器と架空データのみ使用。実音声精度、OSマイク、Keychain、署名済み配布物の入れ替えはこの試験の対象外。
- Windows ZIP候補の自己テスト：モデルハッシュ不一致、欠損エンジン、既存出力先、非Windowsバイナリを拒否。完全な候補は全モデルを含み、未署名・販売不可の表示とマニフェストを同梱。
- 依存準備はFreeなら小さい文字起こしモデルだけを取得し、Proなら要約データ・話者データ・エンジンまで用意。開発者の明示実行でのみ取得し、録音を送らない。

## Windowsの検証経路

`.github/workflows/minutes-windows-editions.yml`：FreeはNSIS、Proは全同梱ZIP64。Windows上の引き継ぎ試験、同梱データでの実文字起こし、Proの実要約を通過したときだけ候補をCI成果物へ保存します。公開GitHub Releasesへは置きません。

通常のNSISは[大容量インストーラーの制限](https://nsis.sourceforge.io/I_get_an_error_when_compiling_large_installers)があるため、約2.5GBの要約データを含むProはZIP64候補にします。ZIP候補は最終販売物ではありません。展開したフォルダー内の`minutes.exe`と`resources/`の配置を維持する必要があります。

旧構成のWindows CI（9585f5f、run 37585936047）は成功を確認しました。これは新しい全同梱Proの版別配布の成功を示すものではありません。新経路の結果は別途記録します。
