# リリースチェックリスト(Mac / Windows 直販)

出す前に上から確認する。署名や規約の詳細は変わるので、最新の公式文書で確認すること。

現行製品の確定状況は `docs/FINAL_HANDOFF_2026-10-07.md` を参照。この一覧にはオンライン認証を想定した旧項目もあるが、minutesの現行ライセンスは端末内で署名検証する方式。認証猶予期間・定期サーバー検証・返金時の即時失効は実装していないため、完了と誤記しない。

## 動作

- [ ] 機内モード(通信なし)で、スコープの全機能が動く(ライセンスの猶予期間内)
- [ ] 通信ログを取り、「通信一覧」にない通信が出ていない
- [ ] 確認画面を通さずに保存・書き出しできる経路がない
- [ ] 最低スペックの実機(Mac は Apple Silicon、Windows は x64)で、処理時間・メモリ・発熱を確認した
- [ ] GPUがない Windows(CPUのみ)でも、遅いなりに動く。遅い場合は画面に目安を表示する
- [ ] 大きなファイル、壊れたファイル、空の入力でも、クラッシュせずエラーを表示する
- [ ] モデルの取得が途中で切れても、再開できる。ディスク容量が足りないときの表示がある

## 配布

- [ ] macOS: 署名と公証を済ませ、ダウンロードしたそのままで起動できる(Intel Mac は非対応と明記)
- [ ] Windows: コード署名を済ませ、SmartScreen の警告が出ないか(または出る場合の案内)を確認した
- [ ] インストール、アップデート、アンインストール(データの削除を含む)を、まっさらな環境で試した
- [ ] ダウンロードの配布先が決まっている(販売プラットフォームの配布機能、または自前のストレージ)

## 販売(外部プラットフォーム)

- [ ] テスト商品で、購入 → キー受領 → アクティベート → 検証 → 台数超過 → 返金 → 失効 を通した
- [ ] 返金後にキーが失効しない場合の扱い(定期検証で検知する)を実装した
- [ ] 商品名・説明・価格が、LPと一致している
- [ ] 日本の購入者向けの価格表示(税込・税別)と、領収書の様式を確認した
- [ ] 事業者の購入者が、仕入税額控除に使える領収書になるか(インボイス制度)を確認し、LPのFAQに書いた
- [ ] 特定商取引法に基づく表記が必要かを確認し、必要なら公開した

## 法務・表現

- [ ] 利用規約(EULA)、プライバシーポリシー、返金ポリシーを公開した
- [ ] サポートの期間と範囲を明記した(`support-policy.md`)
- [ ] `copy-rules.md` に違反する文言がない(アプリ内、LP、note記事)
- [ ] 使っているモデル・ライブラリのライセンスを確認し、必要な表記を入れた
- [ ] 商用利用が禁止されているモデルを使っていない

## 公開後

- [ ] 問い合わせ窓口(メールのみ)と、FAQ を公開した
- [ ] 最初の1週間は、クラッシュ報告と返金理由を毎日確認する
