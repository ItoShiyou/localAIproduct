# core/brand — シリーズ共通のデザイン

- `tokens.css`: 色・字・余白・角丸・影・動きの変数。アプリ(Tauri + React)と Web の両方で `@import` して使う。
- `logo.svg`: シリーズの仮の印(灯りと紙)。名前・アイコンは後で変わる。決まるまでは、アプリではこの印 + 仮称で表示し、Web には名前も印も出さない。
- 思想は `docs/brand-brief.md`(途中を消さない・時間を奪わない・比べない責めない・手元に灯す)。
- **他社(tranext など)の名前・ロゴ・配色・文言はまねない。** 参考にするのは「雰囲気と仕上がりの水準」だけ。
- 変える場合はここだけを直し、`tools/sync_core.sh <slug>`(またはブランドだけなら `core/brand/` を各アプリの `core/brand/` に写す)で配る。

## 見た目の方針(2026-10-05 改訂)

利用者が示した参考(小さなつくり手のサイト・アプリ 3 つ)に共通する雰囲気 =
**静かで正直、平ら、字が主役、余白と細い罫で区切る、色はひとつだけ小さく、動きは最小限** を、わたしたちの言葉に置き換えた。

| 項目 | 前(紙と炎) | いま(静かな工房) | 理由 |
|---|---|---|---|
| 地 | 生成り `#fbf7f0` | 緑みの灰白 `#f3f3ef` | 中立で落ち着いた地に。生成りは競合の配色に近かったため離す |
| 見出し | 明朝 | 太いゴシック(字間 .03em)+ 字間を開けた英字ラベル(.2em) | 参考に共通する「字が主役」の強さ。画面の文字とも揃う |
| 主のボタン | 琥珀のグラデーション + 影 | 墨の塗り、影なし | 平らで、売り込まない |
| 灯り(琥珀) | 面・ボタン・飾りに広く | 点・線・進み具合・再生中など小さく | 「手元に灯す」を、ひとつの小さな灯りとして見せる |
| 面の区切り | カード + 影 | 1px の罫と余白(影はメニュー・ダイアログ・お知らせだけ) | 平ら |
| 暗い帯 | なし | 夜の藍黒 `#1b232b` に灯りの点 | 「夜に手元を照らす」を絵にする(データの扱いなど、約束を述べる場所に使う) |
| 動き | 特になし | 色・下線 .15s、現れる .45s(1回だけ。`prefers-reduced-motion` では止める) | 時間を奪わない |

文字の濃さ: 本文 `--ink`(地の上で 14:1)、補足 `--ink-2`(7:1)、薄い補足 `--ink-3`(4.5:1)。`--flame` は文字に使わない(文字は `--flame-deep`)。
話者の 8 色は、地の上で互いに見分けられる色相を保つ(色だけに頼らず、名前も必ず並べて出す)。
