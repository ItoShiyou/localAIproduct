# core/brand — シリーズ共通のデザイン

- `tokens.css`: 色・字・余白・角丸・影の変数。アプリ(Tauri + React)と Web の両方で `@import` して使う。
- `logo.svg`: シリーズの印(灯りと紙)。名前が決まるまでは、この印 + 各アプリの仮称で表示する。
- 方針は `docs/brand-brief.md`(The Taling. の思想: 途中を消さない・時間を奪わない・比べない・責めない、やわらかい絵本の雰囲気)。
- **他社(tranext など)の名前・ロゴ・配色はまねない。** 画面の構成(サイドバー・カード・下部のプレーヤーなど)は一般的なものとして参考にしてよい。
- 変える場合はここだけを直し、`tools/sync_core.sh --all` で各アプリに配る。
