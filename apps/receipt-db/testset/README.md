# testset(架空のテストデータ)

ここにあるファイルは**すべて架空**です。実在する人・会社・領収書・請求書は使っていません。

- `gen_testset.py` が、乱数を固定して 50 件を自動生成します(会社名・登録番号・金額・日付はすべて作り物。登録番号は T + ランダムな13桁で、実在の事業者とは無関係です)。
- `files/` に生成物、`labels.json` に正解(日付・税込合計・税率・登録番号・支払先)を置いています。正解は生成時に決まるので、人が付けた正解ではありません。
- 内訳: レシート風の画像 15(きれい 5 / 感熱紙の薄れ 5 / 斜め+ノイズ 5)、テキスト層ありの請求書PDF 15、テキスト層なし(画像のみ)の請求書PDF 10、電子領収書のスクリーンショット風 10。
- **限界**: 画像は同じフォント(IPAゴシック)で描いた合成画像です。実際の感熱紙の印字、手ブレ、影、実在するレイアウトの揺れは含みません。ここでの正答率は実データより高く出るため、実データでの精度とは言えません。
- 再生成: `python3 gen_testset.py`(要: pillow, reportlab, pymupdf, numpy、日本語フォント)。
