# テストセット(架空)

**ここにあるデータはすべて架空です。実在する人物・会社・名刺・OCR出力ではありません。**
氏名・会社名・住所・電話・メールは作り物で、メールのドメインは予約済みの `example.com` / `example.org` / `example.net` を使い、
電話番号と郵便番号は `000` を含む形にしています(偶然に実在のものと一致しても、実在の人とは無関係です)。
`cards/` は**OCRエンジンの出力(行ごとのテキストと位置)を手で模した JSON**、`images/` は**同じレイアウトを Pillow で描いた画像50枚**です(いずれも架空)。

| ファイル | 内容 |
|---|---|
| `cards/NN.ocr.json` | OCR出力もどき(`lines[]` に `text`・`bbox`(x,y,w,h)・`vertical`・`confidence`)とメタ情報(`tags`、`side`、`hard`、`note`) |
| `cards/NN.expected.json` | 正解ラベル(氏名・ふりがな・会社・部署・役職・メール・電話・携帯・FAX・郵便番号・住所・URL) |
| `images/NN-a.png` / `NN-b.jpg` | 画像。`a` はきれいな版(背景色・フォントを変更)、`b` は劣化版(傾き4度/-6度、せん断、ぼかし+低コントラスト、影、JPEG圧縮強め、ノイズ)。正解は同じ番号の `cards/NN.expected.json`。`images/manifest.json` に各画像の条件 |
| `gen_images.py` | 画像を生成するスクリプト(Pillow が必要。`python3 gen_images.py`) |
| `gen_cards.py` | 上の2種類のJSONを生成するスクリプト(`python3 gen_cards.py`)。データの手直しはここで行う |

## 構成(25枚)

| 切り口 | 枚数 | 該当 |
|---|---|---|
| 横書き / 縦書き | 21 / 4 | 縦書きは 05, 06, 17, 25 |
| 日本語のみ / 英語のみ / 日英併記 | 18 / 5 / 2 | 英語のみは 07, 08, 09, 16, 23。日英併記は 11, 15 |
| 表面 / 裏面 | 23 / 2 | 裏面は 09(英語表記の裏面)、10(氏名のない裏面) |
| 「難しい」(`hard: true`) | 12 | ルールが想定していない形を意図的に混ぜたもの |

(切り口ごとの数え方。内訳の詳細は各 `*.ocr.json` の `tags` を参照)

## 限界(必ず読むこと)

- 画像50枚は、25レイアウト × (きれい / 劣化) です。**レイアウトは25種類**で、同じ名刺を2通りに描いたものなので、独立した50枚ではありません。「装飾フォント」はゴシック体の別フォント(IPAゴシック / IPAPゴシック / 文泉驛正黑)に影を付けた程度で、実際の装飾書体ではありません。「斜め撮影」は回転とせん断で近似したもので、遠近法のゆがみではありません。
- 縦書きは、全角を正立のまま積み、英数字の連続を90度回して置く描き方です。実物の縦書き名刺とは異なる可能性があります。
- 画像の文字は正しい綴りで描いてあります(`cards/*.ocr.json` のうち『OCRの誤認識を模したテキスト』は、画像では正しい綴りに戻しています。`gen_images.py` の `OVERRIDES`)。
- `cards/*.ocr.json` のOCR出力は**人が書いた理想に近い形**です(実OCRの出力は `examples/ocr_eval.rs --dump` で別に取れます)。実際のOCRは、文字の欠け・順序の乱れ・行の分割と結合・信頼度の分布が違います。ここでの抽出の正答率は、実際の名刺での精度を表しません。
- 正解ラベルは、ルールを書いた同じ作業者が付けています(独立した採点ではない)。
- 実在の他人の名刺は使っていません。実OCRでの測定結果は `docs/spike-results.md` を参照。
