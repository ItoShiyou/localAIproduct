はじめる前に

手元のMacへ。
記録は、そのままに。

現在は配布準備中です。Mac（Apple Silicon）からの公開を予定しています。Windows版は検証・配布準備中です。

無料版とProを選ぶ

無料版は短い音声の文字起こし・編集・テキスト書き出しに。Proは時間制限のない文字起こし、話者の判別、要約や複数形式の書き出しに対応します。Proは購入先から別アプリとしてダウンロードします。購入キーの入力は不要です。

Macにインストールする

  1. 公開後、案内された配布元から自分の版のファイルを入手します。
  2. ZIPを展開し、アプリを「アプリケーション」フォルダーに移します。
  3. アプリを開き、録音時にはmacOSのマイク許可を確認します。
  4. 機密情報を含まない短い音声で、録音・文字起こし・編集・書き出しを試します。

OSが開くことを拒否した場合は、案内された配布元・対応OS・ファイルを確認してください。セキュリティ機能を無効にして起動する必要がある配布物を、正式版として案内することはありません。

無料版からProへ、またはアプリを更新する

  1. 処理を完了し、大切な記録を書き出して保管します。アプリを終了してから、端末のバックアップも取ってください。
  2. 無料版とProの両方を終了します。
  3. 新しいアプリをインストールして起動し、以前の記録が読めるか確認します。

無料版とProは同じ保存場所を使う設計です。同時には起動しないでください。保存データを削除してから入れ替える必要はありません。公開版での引き継ぎ確認を終えてから、配布をご案内します。

容量と対応環境

現在の本体は無料版が約203MiB、Proが約3.13GiBです。Proは要約に必要なデータも含みます。ダウンロードと展開のため、本体の容量に加えて空き容量を確保してください。録音の保存にも容量を使います。最終的な対応OS・推奨メモリ・配布容量は公開時にご案内します。

インターネットなしで使う

インストール後の音声処理はオフラインで行えます。購入・入手・更新は別の操作です。必要なら別のパソコンで入手したアプリを、ご自身の組織の規則に従って移すこともできます。
