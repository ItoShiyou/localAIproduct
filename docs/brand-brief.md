# ブランドとデザインの方針(下書き・2026-10-04)

## 前提(利用者の指示)
- 参考画像のアプリ(tranext)は他社製品。**名前・ロゴ・配色・細部はまねない**。画面の「構成」(左のライブラリ、上の題名と状態、カード型の文、下部の波形付きプレーヤー、話者の色)だけを参考にする。
- ブランドの思想は、利用者の別プロジェクト **The Taling.** の考え方を取り入れる(Google Drive の提案スライドより):
  - 「人は結果ではなく、途中に救われる」「途中を消さない」
  - 時間を奪わない設計(無限スクロールをしない、必要なときだけ開く)
  - 比較・数値の競争をしない。失敗や停滞も物語の一部として扱い、責めない
  - 絵本のような、やわらかい雰囲気
- 「ロウソク行脚」は手元のファイル・Drive からは見つからなかった → **内容を利用者に確認する**。

## このシリーズ(端末の中で動く買い切りアプリ)への当てはめ案
- 「あなたの言葉と記録を、手元に灯しておく」— 外に送らない・消さない・急かさない。
- 色: 灯り(暖かい生成り・琥珀)を基調、話者色は落ち着いた色相。トークンとして `core/brand/`(色・字体・角丸・余白・部品)に抽出し、全アプリと Web で共有する。
- 文言: 断定しない(copy-rules)、責めない、成果より途中を大事にする言い回し。
