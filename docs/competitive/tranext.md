## こちらの強み(相手の公開情報に見当たらないもの)

- **ノイズ除去**(オン/オフ、除去後の音声の書き出し)
- **用語辞書**(誤りやすい表記→正しい表記、認識のヒント、CSV)
- **確認・修正の速さ**: 要確認の文だけ巡回、入力中の自動一時停止、文を押して再生位置へ、検索・置換、元に戻す
- **議事録としての形**: 議題・決定事項・ToDo(担当・期限)、タグ・絞り込み、確定してから書き出す流れ
- **通信がさらに少ない**(AI モデル検索・Web 検索をしない)。モデル同梱で最初からオフライン
- 範囲指定の文字起こし、1時間録音の中断・再開(区間ごとに保存)

## 対抗の優先順位(案)

1. **リアルタイム録音と文字起こし**(マイク)— 実装中。相手は Pro 限定 → こちらは標準機能にする案
2. **パソコン音声の録音**(Web 会議をボットなしで)— macOS は ScreenCaptureKit、Windows は WASAPI ループバック。次の作業
3. **要約・質問への回答**(端末内の小型言語モデル)— 承認済み。相手は資料作成まで踏み込んでいるので、まず「議事録の要約・決定事項・ToDo の下書き」に絞って質で勝つ
4. **Windows 版**(相手は Windows/Linux も対応済み)
5. 書き出しの形式を増やす(VTT、Excel の ToDo 表、動画への字幕)。精度・速さの段階選択(小さいモデルの追加)
6. 試用版(期間限定の全機能)— 販売プラットフォームのライセンス機能で
